# 100 Days of Code - Python

Este repositório reúne minhas soluções para os desafios propostos no curso **“100 Days of Code: The Complete Python Pro Bootcamp”**.

## 📌 Objetivo

Documentar minha evolução ao longo dos 100 dias, armazenando:

- Respostas aos exercícios  
- Projetos desenvolvidos  
- Anotações para revisão e estudo  

## 📚 Estrutura

Cada módulo do curso corresponde a um “dia” de aprendizado, com uma progressão do nível básico ao avançado em Python.

## 🚀 Conteúdos abordados

- Fundamentos da linguagem Python  
- Ciência de dados  
- Automação de tarefas  
- Desenvolvimento web  
- Criação de jogos  
- Construção de aplicações  

## 🧠 Finalidade

Este repositório funciona como um registro da minha evolução e também como material de apoio para revisões futuras.
